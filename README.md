# KyoshinViewer

KyoshinViewerは、強震モニタの表示と、Android端末の加速度センサーを利用した揺れの計測を行うアプリです。

## 主な機能

### 強震モニタ
- 強震モニタのWebページをアプリ内に表示
- 表示内容の再読み込み

### 加速度センサーによる揺れの計測
- 端末内蔵の加速度センサーを使用
- X・Y・Z各軸の加速度を取得
- 各軸にリアルタイム震度算出用のフィルターを適用
- 3軸の加速度から合成加速度を算出
- リアルタイム震度相当値と加速度を表示
- 加速度波形を表示
- センサー情報とサンプリング周波数を確認

### 計測データの記録
- 計測結果をCSV形式で保存
- 保存した記録の一覧表示
- 記録データの再生
- 記録の削除とCSVファイルのエクスポート
- 震度相当値を基準とした自動記録・自動停止

## 震度相当値について

本アプリが表示する値は、気象庁が発表する正式な計測震度ではありません。

端末の加速度センサーから取得した値にフィルター処理を行い、3軸合成加速度から算出した参考値です。

震度階級は次の10段階で表示します。

- 震度0
- 震度1
- 震度2
- 震度3
- 震度4
- 震度5弱
- 震度5強
- 震度6弱
- 震度6強
- 震度7

気象庁の正式な震度情報や防災情報の代わりには使用しないでください。

## 計測時の注意

- 端末の加速度センサーを利用するため、端末の機種やセンサー性能によって計測結果が異なります。
- 端末は安定した場所に置いて計測してください。
- 計測中に端末の向きを変えると、その動きを揺れとして検出する場合があります。
- 机や棚など、端末を置いた場所自体の振動も計測結果に影響します。
- 本アプリの計測値は参考値であり、地震計による観測値とは異なります。

## CSVファイルについて

記録データはCSV形式で保存します。

主な記録項目は次のとおりです。

- タイムスタンプ
- X軸加速度
- Y軸加速度
- Z軸加速度

加速度はフィルター処理後の値をgal（cm/s²）単位で記録します。

CSVのヘッダーには `RealtimeIntensity` という識別文字列を使用しています。これは本アプリ独自の記録形式であり、気象庁や観測機関の公式な観測データ形式ではありません。

## 動作環境

- Android 8.0（API 26）以上
- 加速度センサーを搭載した端末

端末の機種やAndroidのバージョンによって、センサーの動作や取得できるサンプリング周波数が異なる場合があります。
